# ScrDeck v1.0.0 (V1 - Initial Public Release)

### Your Android. Your Workspace.

We are proud to present **ScrDeck V1 (v1.0.0)** — an independent, open-source graphical companion for scrcpy and Android Debug Bridge (ADB). ScrDeck transforms command-line Android mirroring and device administration into an intuitive, high-performance desktop workspace.

---

### Key Highlights & Features

#### 1. Setup Assistant & Automatic Toolchain Verification
- **One-Click Discovery**: Automatically detects existing local installations of scrcpy and ADB.
- **Managed Toolchain**: Download and configure official, verified upstream tools directly within the app without manual environment configuration.
- **Manufacturer Guides**: Visual, step-by-step onboarding for enabling Developer Options and USB Debugging across all major Android OEMs (Samsung, Xiaomi, Google Pixel, OnePlus, OPPO, etc.).
- **RSA Security Authorization**: Live verification and guidance for accepting Android RSA debugging prompts.

#### 2. Overview & System Readiness
- **Device Dashboard**: Comprehensive status center displaying active toolchain versions, real-time connection state, and discovered hardware.
- **Primary Device Card**: Detailed device overview featuring Android OS version, battery percentage, active display resolution, and one-click quick actions.
- **Instant Mirroring Launchers**: Jump straight into your favorite mirror sessions with predefined configuration profiles.

#### 3. Multi-Device Discovery & Wireless Management
- **Multi-Device Target Selector**: Manage and switch between multiple connected Android devices seamlessly.
- **Wireless Debugging**: Direct support for wireless pairing and TCP/IP connection without keeping your device tethered by USB.
- **Driver Troubleshooting**: Built-in driver diagnostics and verified links to manufacturer OEM USB drivers to resolve connection issues quickly.

#### 4. Mirroring Studio
- **Basic Controls**: Effortlessly adjust display scaling, frame rates (up to 120 FPS), modern video codecs (H.264, H.265, AV1), audio forwarding, and window behavior (always on top, fullscreen, borderless).
- **Display & Power Optimizations**: Options to turn the physical device screen off during mirroring, prevent PC sleep, or stay awake.
- **Advanced Mode**: Fine-tune display orientation, custom rectangular crop boundaries, maximum bitrates, and direct session recording (MP4 and MKV).
- **Custom Arguments**: Transparent argument builder with real-time conflict checking, security validation, and an exact live command preview.
- **Non-Destructive Session Control**: Start and safely stop ScrDeck-managed scrcpy sessions without terminating other background ADB workflows.

#### 5. Preset Manager
- **Curated Profiles**: Pre-configured presets for *Balanced*, *Low Latency Gaming*, *High Quality Presentation*, and *Battery Saver*.
- **Custom Presets**: Create, clone, modify, and manage an unlimited number of personalized mirroring templates.
- **Export & Import**: Share and back up your presets using portable JSON profiles.

#### 6. Activity Timeline & Diagnostics
- **Live Event Log**: Chronological timeline tracking device connection lifecycles, scrcpy outputs, and application status.
- **Smart Error Translation**: Human-readable explanations for common ADB and scrcpy error codes with recommended solutions.
- **Sanitized Export**: Easily export diagnostic logs with automatic redaction of device serial numbers, IP addresses, and personal directories.

#### 7. Settings & Experience
- **Theme Support**: Polished Dark, Light, and System themes built with an industrial utility design system.
- **Configurable Toolchain**: Point to custom executable paths for scrcpy and ADB anytime.
- **Full Transparency**: Built-in third-party licensing notices, attribution disclaimers, and open-source project links.

#### 8. Packaging & Portability
- **Self-Contained Installer**: Updated NSIS installer with bundled WebView2 runtime loader dependencies for instant out-of-the-box operation on any Windows 10/11 system.
- **Full Portable Archive**: Dedicated `.zip` portable package including all required runtime libraries for zero-install, plug-and-play usage.
