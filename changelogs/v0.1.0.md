# ScrDeck v0.1.0

### Your Android. Your Workspace.

Initial release of ScrDeck — an independent, open-source graphical companion for the original scrcpy project and Android Debug Bridge (ADB).

---

### Features & Capabilities

#### 1. Setup Assistant
- Guided onboarding workflow for first-time users.
- Automated discovery and verification of scrcpy and ADB toolchains.
- Option to install the official managed toolchain package or connect existing local tools.
- Step-by-step instructions for enabling Developer Options and USB Debugging across device manufacturers.
- Clear RSA authorization guidance with real-time connection verification.

#### 2. Overview & System Readiness
- Live dashboard displaying scrcpy version, ADB state, and discovered device count.
- Dedicated primary device card with connection type, Android release, battery level, and one-click quick actions.
- Instant preset launchers and chronological activity highlights.

#### 3. Device Discovery & Management
- Multi-device discovery with explicit target selection.
- Distinct status badges for authorized, authorization pending, offline, and disconnected states.
- Support for Wireless Debugging with secure, private pairing code entry.
- Built-in USB and OEM driver troubleshooting assistant with direct links to verified manufacturer resources.

#### 4. Mirroring Studio
- **Basic Mode**: Simple controls for display scaling, maximum frame rate, video codecs (H.264, H.265, AV1), audio forwarding, window options, and screen power behavior.
- **Advanced Mode**: Detailed options for window titles, display orientation, crop dimensions, and session recording (MP4/MKV).
- **Custom Arguments**: Transparent editor with real-time argument conflict detection, safety validation, and live command preview matching the exact executed command.
- **Session Control**: Seamless start and stop functionality targeting only ScrDeck-managed sessions without disrupting unrelated ADB tasks.

#### 5. Preset Manager
- Shipped templates for Balanced, Low Latency, High Quality, Presentation, and Battery Conscious profiles.
- Create, duplicate, customize, and delete custom user presets.
- Portable schema-versioned JSON import and export.

#### 6. Activity & Diagnostics
- Local activity timeline recording connection events, scrcpy outputs, and session lifecycles.
- Error translation system explaining common issues and providing actionable next steps.
- Search and severity filtering for fast troubleshooting.
- One-click sanitized diagnostic export with automated redaction of device serials, IP addresses, and user paths.

#### 7. Settings & About
- Dark, Light, and System theme support with industrial utility visual design.
- Custom toolchain paths and process exit policies.
- Comprehensive third-party notices, official project links, and attribution disclaimers.
